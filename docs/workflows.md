# Workflow Map

This document maps common creator requests to a practical sequence. Ask Codex to follow the relevant workflow by name, or use one of the prompt recipes in `.codex/prompts/`.

| Workflow | Deliverable | Inputs that help |
|---|---|---|
| Audit | Evidence-based health report, gaps, prioritized 30-day plan | Channel URL, goals, metrics |
| SEO | 3 title options, description, tags, chapters when transcript/timing supplied, hashtags | Topic, transcript, audience, language |
| Script | Retention-aware script with visual cues | Topic, audience, length, tone |
| Hook | 5 opening approaches with rationale | Topic and promise |
| Thumbnail | 3 distinct visual briefs | Video topic, title options, visual assets |
| Strategy | Positioning, content pillars, cadence, milestones | Niche, audience, creator capacity |
| Calendar | 30-day or monthly publishing plan | Frequency, formats, dates |
| Shorts | Vertical short script, visual beats, title/caption | Topic and target duration |
| Analyze | Interpret supplied Studio data and identify bottlenecks | Metrics/export/screenshots |
| Repurpose | Channel-specific adaptations for Shorts, Reels, blog, email, social | Source video/script and rights |
| Monetize | Revenue stream fit and next experiments | Niche, geography, audience profile |
| Competitor | Public competitor content patterns and content gaps | Competitor channels and audience |
| Metadata | Copy-ready upload package | Transcript, title, duration |
| Ideate | Ranked topic concepts and testable hypotheses | Niche, audience, recent uploads |

## Suggested end-to-end sequence

1. Ideate — choose a topic based on audience relevance and available evidence.
2. Script and hook — draft the promise, structure and opening.
3. Thumbnail and SEO — keep title, promise and thumbnail aligned.
4. Metadata — generate the final upload package from the actual video.
5. Analyze — after publication, compare results against the channel’s own baseline.
6. Update strategy — document lessons and reuse only what is supported by evidence.

## Safe fallback

If APIs or browsing are unavailable, continue using user-provided information and label the analysis as qualitative. Do not invent live metrics.
