# YouTube Shorts Package

Create a vertical-first package for the requested topic:
- One-sentence promise and 3 hook choices.
- Spoken script paced for the requested duration.
- Visual/shot changes, captions emphasis and sound suggestions.
- Title, description/caption, hashtags and CTA.
- Suggested first-frame composition and ending/loop where natural.
- Factual claims to verify.
Don't promise views or virality. Repurpose only source footage the user has permission to use.
