# YouTube Channel Audit

Follow the audit workflow in `docs/workflows.md`.

1. Confirm the channel URL/handle, niche, audience, geography, language and primary goal when available.
2. Gather public channel/video data from official API or current sources if access is available. Request private analytics from the user when needed.
3. Examine packaging (titles/thumbnails/descriptions), content consistency, format mix and upload rhythm.
4. Separate verified observations from hypotheses and unavailable metrics.
5. Give an executive summary, evidence table, top 5 fixes ranked by impact/effort, and a 30-day action plan.
6. Do not assign benchmark-based scores without a cited, relevant benchmark. Where data is absent, use “not assessed”.
