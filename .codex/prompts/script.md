# Retention-Aware YouTube Script

Given topic, audience, language, tone and target duration:
1. State the viewer promise in one sentence.
2. Draft 3 hooks and select the strongest with a reason.
3. Write a complete script broken into purposeful sections with approximate timestamps.
4. Add visual/B-roll/graphic cues and pattern changes where they serve clarity.
5. Include a midpoint reset only where appropriate; don't add arbitrary interruptions.
6. Place CTA naturally after value is delivered.
7. List factual claims requiring verification and cite sources for researched claims.
8. End with a concise production checklist.
