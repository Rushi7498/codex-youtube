# YouTube Upload Metadata

Generate a copy-ready package from the final video transcript/outline:
- 3 title candidates and recommendation
- Description with relevant links supplied by user
- Chapters only when actual timestamps/duration are available
- Relevant tags and a small number of appropriate hashtags
- Pinned comment, cards/end-screen suggestions, playlist/category suggestions when context supports them
- Final upload checklist
Never invent URLs, timestamps, credentials, or policy claims.
