# YouTube Video SEO Package

Input: video topic or draft, target audience, language, video transcript/outline and target geography if relevant.

Deliver:
1. A concise keyword intent hypothesis (not invented search volume).
2. Three title variants: search-oriented, curiosity/browse-oriented, balanced.
3. Recommended title and reason.
4. Copy-ready description; only add chapters if reliable timestamps or duration/structure are supplied.
5. Relevant tags within platform limits and 3–5 relevant hashtags when suitable.
6. Pinned comment and CTA.
7. Validation notes: assumptions, character counts if claimed, source links for live research.
Avoid keyword stuffing and never claim unverified search demand.
