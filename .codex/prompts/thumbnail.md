# YouTube Thumbnail Brief

Deliver three distinct concepts, not superficial variations:
- Concept name and intended emotional/curiosity angle.
- Focal subject, composition, background, lighting, contrast and color direction.
- Suggested on-image text (ideally brief) and title-thumbnail complementarity.
- Mobile legibility checklist and potential misleading-click risk.
Use 16:9 as the default YouTube thumbnail shape. If image generation is available and requested, create the actual visual; otherwise provide production-ready briefs.
